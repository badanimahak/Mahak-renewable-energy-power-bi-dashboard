# Mahak-renewable-energy-power-bi-dashboard
Power BI dashboard analyzing renewable energy generation, revenue, operating profit, and plant downtime across wind, solar, and hybrid energy plants.
Renewable Energy Power BI Dashboard

Overview

An interactive Power BI dashboard analyzing renewable energy generation, revenue, operating profit, and downtime across Wind, Solar, and Hybrid power plants.

Key Features

- Energy generation by plant type and year
- State-wise revenue analysis
- Plant-wise downtime comparison
- KPI cards for energy, revenue, profit, and downtime

Tools Used

- Microsoft Power BI
- Power Query
- CSV Dataset

Files

- Renewable energy dataset (".csv")
- Power BI dashboard (".pbix")
- Project presentation (".pptx")

Objective

To transform renewable energy data into meaningful visual insights for performance monitoring and data-driven decision-making.
